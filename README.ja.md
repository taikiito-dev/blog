# blog.taikiito.com

このリポジトリには、[blog.taikiito.com](https://blog.taikiito.com)(GitHub Pagesで配信)のビルド済み静的サイトだけが置かれています。

執筆はprivateな原稿リポジトリで行っています。下書き・書き直し・編集履歴はそちらだけに残ります。このリポジトリには、公開のたびに完成したHTMLだけが新しく届きます。記事の中身や執筆の履歴はここには一切ありません。

Built with [Hugo](https://gohugo.io/) + [PaperMod](https://github.com/adityatelange/hugo-PaperMod).
